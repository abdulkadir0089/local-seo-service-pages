# Local SEO for a Landscaping Company's Service Pages

> **Case study** · On-page & local SEO · Client: US landscaping & hardscape company (name kept private)

## Scope
On-page SEO across the company's service pages, in batches:

- Landscape maintenance, landscape installation, poolscapes, retaining walls and seating walls
- Patios, hardscape installation, stone steps, walkways, driveways, fire pits, fireplaces and outdoor kitchens
- A seasonal holiday decorating service page and the projects gallery

## What I did on each page
- Chose a focus keyword that actually appears in the content
- Wrote the SEO title and meta description
- Checked the canonical URL and that the page is indexable
- Added internal links between related services
- Filled in missing image alt text

## Holiday decorating service page
- Title and meta description targeting the local service search, ending in a "Get a quote" call to action
- Service-area section naming 12 nearby towns
- 6-question FAQ covering scope, booking, takedown, commercial work and weather
- Trust details: licence numbers, phone numbers and address
- Descriptive, keyword-based image file names
- Caught that the page was set to **noindex** and was reusing another page's SEO title

## Redirect audit
Checked the site's URLs for broken pages and redirects needed after the redesign.

## Issues flagged for next steps
- Icon images with alt text copied from another page
- 100+ gallery images on the projects page with no alt text and generic file names
- The projects page loading the same images twice
- No social share image (og:image) on the projects page
- A footer link using a raw `?page_id=` URL instead of the page address
